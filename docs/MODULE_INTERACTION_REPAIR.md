## 根因及修改

- 网站运行于外部 `frontend-dependencies` 缓存副本，修改源码不会自动同步。`start.ps1` 现在在复用运行进程之前同步该副本。本轮已同步并核实 HTTP 返回新组件。
- 后端使用 `groupId/parent`，旧编辑器却仅使用 `layerRole/moduleMemberIds`。新增共享几何函数，兼容已有容器和嵌套模块；明确区分单个对象、多选、所属模块。
- 图片透明像素过去也会吞掉整个矩形内的点击。按实际 PNG alpha、裁切、旋转与画布缩放做命中检测；透明处点击/双击向下寻找可见对象。
- 属性面板和鼠标移动统一更新几何与 AST bbox；整组尺寸调整同步文字字号。单击不再触发零位移的数据重写。取消拖动保留原位置。
- 网页文字行距原先写死为 1.12，未使用 Layout 中的 1.0。现在读取同一 `lineSpacing` 字段。没有声称字体已完全复刻原图。
- 重复轮廓合并曾只合并 carrier 标记，丢掉实际闭合轮廓；现在同时合并实测 mask。将窄范围、未被任何对象拥有的抗锯齿边缘保存为所属模块的独立资产，不改变既有 owner。
- 新的底板补齐仅填充位于已成功提取子对象下方的透明孔洞。要求浅色底板的空间覆盖和拟合误差门禁；可见源像素、纹理和未知区域不改动。无整块涂白、LaMa 或多轮覆盖。
