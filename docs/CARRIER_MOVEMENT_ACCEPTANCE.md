# 混合底板与照片移动残影修复（2026-10-17）

用户拖动右上模块时暴露了真实缺陷：底板仍持有五张照片的边框、箭头和色条。之前的透明孔洞计数及 7 个重建底板验收没有覆盖该资产。本轮先将问题快照推送为 `b2b7412`，随后修复并扩大验收范围。

## 实现

- 对接近凸形但有局部断口的轮廓，用原图四侧边缘独立验证；只有直边和圆角也得到原图支持时才恢复圆角外框，避免凸包斜切标题或凭 bbox 造底板。
- 独立照片先取得完整核心及窄浅色阴影区域，邻近饱和箭头不纳入照片。分散检测条不再吞并照片，剩余箭头拆为独立对象，微小片段合并保留。
- 可靠的矮条形底板也进入纸面重建。主要为黑色的二值示意图保留为视觉对象；彩色模块的原有识别规则仍保留。
- 重建底板统一使用自身测得的平滑场，不再用局部子对象白底覆盖它；后续补色不能超出已验证轮廓。
- 普通前景资产不再自动补造大片底色，前景边缘也不得向独立照片下方补色，避免照片移走后留下白框或箭头碎片。
- 纸面与最终文字叠合分别审计：新字体覆盖原空白处不应误报，非文字覆盖及错误文字底材仍会被拒绝。审计返回异常坐标以便定位。
- 对象完整性同时记录全部底板的孔洞、未验证边界和未重建列表；零孔洞不再代表视觉合格。
